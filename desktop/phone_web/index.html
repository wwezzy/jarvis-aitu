Твой Jarvis

Открой личную защищённую ссылку или вставь ключ, созданный на ноутбуке. Пароли сервисов здесь не нужны.

Ключ остаётся только в этой вкладке. План не сохраняется в кэше телефона.

Команды ноутбука

Удалённое управление не подключено. Нужны отдельный ключ и разрешение на ноутбуке.

Этот ключ хранится только в текущей сессии вкладки. Команды доступны по списку; свободного запуска программного кода нет.
