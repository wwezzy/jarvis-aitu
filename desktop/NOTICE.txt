Microphone capture starts only after explicit enablement, including a saved
automatic-listening choice. Recognition is local by default. Optional cloud
transcription requires a separate explicit flag and an environment API key;
only a bounded command segment of at most 12 seconds after verified wake
authorization may be uploaded. Ambient wake detection stays local. Captured
audio and the outgoing WAV are held in bounded RAM buffers, not saved by
Jarvis. Provider handling of an explicitly uploaded segment is subject to
that provider's terms; this is not a claim of zero provider retention.
Optional cloud conversation sends the submitted question. History and plan
context each require an additional separate opt-in; notes are not attached
automatically. No model response authorizes computer actions. Local data
remain on this Windows account; uninstall retains them for future reinstalls.

Camera gestures have been removed from the desktop application. MediaPipe,
OpenCV and the gesture worker are excluded from new application bundles.
Optional Windows Hello uses Windows' owner-consent interface; Jarvis does
not capture camera frames or keep biometric templates.
